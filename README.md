# Profession-Management-System

A simple Employee List web application built using **HTML, CSS, and JavaScript**. It allows users to add employee details, view the employee list, and delete employees.

## Features

- Add employee details
- Enter employee name, profession, and age
- View added employees
- Delete employees from the list
- Simple and responsive user interface
- Form validation for required fields

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
employee-list/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter an employee's name, profession, and age.
5. Click **Add User** to add the employee to the list.

## Note

Employee details are stored temporarily in the browser using JavaScript. The list resets when the page is refreshed.
